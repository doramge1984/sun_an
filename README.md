# 순천대 AI 연수 — 사전 안내 페이지

이 폴더에는 신청자분들께 전달할 사전 안내 페이지(`index.html`) 하나만 들어 있습니다.
(사전 설문 참여 안내 + 구글 개인계정 준비 7단계)

## GitHub Pages로 배포하는 방법

1. GitHub에서 새 저장소(Repository)를 만듭니다. (이름은 자유롭게, 예: `suncheon-ai-prep`)
2. 이 폴더 안의 `index.html` 파일을 저장소에 업로드합니다.
   - GitHub 웹사이트에서: 저장소 페이지 → "Add file" → "Upload files" → `index.html` 드래그 앤 드롭 → Commit
3. 저장소 페이지에서 **Settings → Pages**로 이동합니다.
4. "Branch"를 `main` (또는 `master`), 폴더는 `/ (root)`로 선택하고 저장합니다.
5. 잠시 기다리면 다음과 같은 주소로 페이지가 열립니다.
   `https://<내계정이름>.github.io/<저장소이름>/`
6. 이 링크를 신청자분들께 카카오톡·문자·메일로 전달하시면 됩니다.

## 참고
- `index.html` 안에 이미지(스크린샷)가 모두 포함되어 있어서, 이 파일 하나만 올리면 됩니다. 별도 이미지 파일을 추가로 올릴 필요가 없습니다.
- 내용을 수정하고 싶으시면 `index.html`을 텍스트 편집기로 열어 직접 고치거나, 다시 Claude에게 요청해서 새 버전을 받으실 수 있습니다.
